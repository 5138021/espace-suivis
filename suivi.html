⚙ Configuration — 1 minute

Les suivis remplis depuis suivi-arbitrage.html et suivi-en-direct.html sont enregistrés dans un fichier suivis.json versionné directement dans votre dépôt GitHub. Pour afficher l'historique ici :

  1. Ouvrez le haut du script de cette page
  2. Renseignez GITHUB_OWNER (compte/organisation) et GITHUB_REPO (nom du dépôt) — mêmes valeurs que dans les 2 formulaires
  3. Republiez la page ; aucune clé n'est nécessaire ici si le dépôt est public
